# SAP BTP Capability Pillars (SAP Learning framing)

## Overview

SAP Learning materials use more than one capability framing for SAP Business Technology Platform. This note records the five-pillar framing from a dated SAP Learning overview and keeps it distinct from the four-core-pillars-plus-foundation framing used elsewhere.

## Interview Summary

In the SAP Learning course Becoming an SAP BTP Solution Architect, unit Exploring SAP BTP: An Overview, SAP presents five capability pillars of SAP Business Technology Platform: Application Development and Automation, Data and Analytics, Integration, Artificial Intelligence, and Platform Foundation. Platform Foundation is the supporting foundation layer in that five-pillar framing. Other SAP Learning material describes four core solution pillars and treats Platform Foundation as the supporting layer rather than a fifth peer pillar, so an interview answer should name the framing and source instead of claiming one fixed inventory is universal across all SAP materials.

## 60 Second Interview Answer

When an interviewer asks for the five pillars of SAP BTP, I answer from the SAP Learning overview Exploring SAP BTP: An Overview in Becoming an SAP BTP Solution Architect. That material frames five capability pillars: Application Development and Automation, Data and Analytics, Integration, Artificial Intelligence, and Platform Foundation. I keep Platform Foundation as the foundation layer in that five-pillar list, and I note that other SAP Learning content uses four core solution pillars with Platform Foundation as the supporting layer — so I do not silently merge the two framings.
