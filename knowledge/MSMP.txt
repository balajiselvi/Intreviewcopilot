Multi Stage Multi Path in SAP GRC Access Control 

 

The MSMP Workflow is the central engine in SAP GRC Access Control that drives how access requests move through multiple approval stages using predefined paths and rules. 

 

Here’s a crisp breakdown to help you configure it efficiently: 

 

🟢 MSMP Workflow Configuration Steps: 1️⃣ Process Global Settings 

2️⃣ Maintain Rules 

3️⃣ Maintain Agents 

4️⃣ Variables & Templates 

5️⃣ Maintain Paths 

6️⃣ Maintain Route Mapping 

7️⃣ Generate Versions 

 

🔶 Quick Notes: 

Steps 1–4 may be pre-configured with BC Set activation. Adjustments are needed for custom rules, agents, or notification templates. 

 

Step-by-Step Insights: 

▶️ Process Global Settings - Configure escalation and notification triggers. 

▶️ Maintain Rules - Define the initiator and notification logic (e.g., REQUEST_SUBMISSION). 

▶️ Maintain Agents - Assign responsible approvers for each workflow stage. 

▶️ Variables & Templates - Customize or reuse SAP notification templates. 

▶️ Maintain Paths - Define workflow steps and assign agents + notification events. 

▶️ Route Mapping - Map Rule ID, Path ID, and Result Value correctly. 

▶️ Generate Version - Simulate, validate, and activate the configuration.
